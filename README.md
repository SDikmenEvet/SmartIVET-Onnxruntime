# SmartIVET ONNX Runtime pods

Mirror of the ONNX Runtime 1.28.0 CocoaPods archives (`onnxruntime-c`, `onnxruntime-objc`), because `download.onnxruntime.ai` currently serves an invalid TLS certificate.

The archives are unmodified Microsoft builds (MIT licensed, see LICENSE inside each zip), downloadable from the `1.28.0` release.
